# Downpeed 设置菜单路线图

本文档规划设置菜单的信息架构、实施顺序和数据边界。实际导航只在对应能力形成可运行闭环后出现，不提前放置空菜单或“即将上线”占位页。

## 规划后的菜单结构

### 偏好设置

1. **外观**（已有）：深浅主题、跟随系统、界面语言。
2. **工作区**（已有）：侧栏默认状态、侧栏宽度和后续的列表密度。
3. **通知与快捷键**（已完成首个闭环）：已支持完成通知开关和 `⌘/Ctrl + N` 新建下载；通知声音、自定义快捷键和冲突检查留待 M4。

### 下载与网络

1. **下载与文件**（M4）：默认保存位置、重名策略、临时文件、完成后动作。
2. **速度与调度**（M4）：最大并发任务、全局限速、重试次数和计划下载。
3. **连接与代理**（M4）：系统代理、HTTP/SOCKS5 代理、连接超时和代理连通性检查。
4. **BitTorrent**（M3）：默认 Tracker/DHT 策略、文件选择、上传限速和做种规则。必须在 BT 引擎契约完成后再显示。

### 系统

1. **本机引擎**（已有）：连接状态、引擎版本和手动重新检查。
2. **数据与诊断**（M4）：数据库与日志位置、诊断导出、备份、恢复和迁移。
3. **隐私与远程访问**（M5）：本地监听边界、远程访问开关、认证与已授权设备。
4. **关于与许可证**（已完成首个闭环）：已展示客户端、引擎、API 和运行平台版本，并提供 Flutter 依赖许可证页；更新检查与完整发布构建信息留待 M4。

## 实施优先级

| 顺序 | 菜单 | 前置条件 | 首个可交付闭环 |
| --- | --- | --- | --- |
| 1 | BitTorrent | M3 Torrent/Magnet 解析和安全默认值完成 | 展示并保存 BT 默认策略 |
| 2 | 关于与许可证 | 已完成首个闭环 | 后续接入更新检查和发布构建信息 |
| 3 | 数据与诊断 | 引擎提供脱敏后的路径与导出契约 | 查看数据/日志位置并导出诊断包 |
| 4 | 下载与文件 | `GET/PUT /api/v1/settings` 具备版本和校验 | 默认保存位置与重名策略 |
| 5 | 速度与调度 | 引擎支持运行时安全更新调度器 | 并发数与全局限速 |
| 6 | 连接与代理 | 凭据安全存储和代理测试契约完成 | 系统代理与手动代理切换 |
| 7 | 通知与快捷键 | 已完成首个闭环 | 后续增加通知声音、快捷键自定义与冲突检查 |
| 8 | 隐私与远程访问 | M5 认证、TLS 边界和审计日志完成 | 显式启用远程访问并管理授权 |

## 数据与安全边界

- 主题、语言、工作区布局、通知和快捷键属于 Flutter 本机偏好，由 `PreferencesService` 持久化。
- 下载、调度、网络、BT、数据与远程访问属于 Go 引擎业务设置，只能通过版本化 API 读写。
- 代理密码、远程令牌等敏感值不进入 GetStorage、普通日志或诊断包；界面仅持有安全引用。
- 设置更新必须返回引擎已接受的最终值，Flutter 不乐观持久化业务配置。

## 通用验收标准

1. 宽屏只显示当前分组内容，窄屏继续使用菜单到详情的主从导航。
2. 每个控件必须说明生效时机、作用范围和对进行中任务的影响。
3. 支持中英文、200% 文字缩放、键盘焦点和读屏语义，长路径与长错误不溢出。
4. 业务设置写入失败时保留服务端原值并显示本地化错误，不伪装成已保存。
5. 新增菜单需要 Widget 测试；涉及引擎设置时同时覆盖 API 契约、校验、持久化和重启恢复。
