# Downpeed 设置菜单路线图

本文档规划设置菜单的信息架构、实施顺序和数据边界。实际导航只在对应能力形成可运行闭环后出现，不提前放置空菜单或“即将上线”占位页。

## 规划后的菜单结构

### 偏好设置

1. **外观**（已有）：深浅主题、跟随系统、界面语言。
2. **工作区**（已有）：侧栏默认状态、侧栏宽度和后续的列表密度。
3. **通知与快捷键**（已完成应用内固定快捷键闭环）：已支持完成通知开关、`⌘/Ctrl + N` 新建下载、`⌘/Ctrl + F` 搜索任务、`⌘/Ctrl + ,` 打开设置、`⌘/Ctrl + R` 刷新当前内容、三平台关闭到托盘，以及系统登录启动与按偏好静默运行；通知声音、自定义快捷键、冲突检查和可选 OS 全局热键留待 M4 后续。

### 下载与网络

1. **下载与文件**（已完成三个闭环）：已支持默认保存位置、系统下载文件夹初始化、重名时停止或自动生成副本名，以及默认关闭的“完成后在文件管理器中显示”；临时文件管理选项留待 M4。
2. **速度与调度**（已完成首个闭环）：已支持最大并发任务、全局下载限速、自动重试次数和计划下载的持久化与运行时更新；后续增加更细粒度的单任务策略。
3. **连接与代理**（已完成首个闭环）：已支持直连、系统/环境代理、HTTP/SOCKS5 代理、连接与响应头超时，以及固定 HTTPS 目标的连通性检查；代理密码由三平台系统安全凭据库保存并只注入引擎内存。
4. **BitTorrent**（已完成首个安全闭环）：可设置新任务的 Peer 连接预算；Tracker/DHT/PEX/WebSeed、IPv6、入站、上传和做种由 Go 内核锁定关闭并在界面中明确展示。未来逐项通过独立安全门禁后再扩展可配置能力。

### 系统

1. **本机引擎**（已有）：连接状态、引擎版本和手动重新检查。
2. **数据与诊断**（已完成首个闭环）：已支持脱敏数据/数据库位置、数据库大小、日志保留状态、任务计数和诊断 ZIP 导出；备份、恢复和迁移留待 M4。
3. **隐私与远程访问**（M5）：本地监听边界、远程访问开关、认证与已授权设备。
4. **关于与许可证**（已完成两个闭环）：已展示客户端、提交号、发布通道、构建时间、引擎、API 和运行平台版本，并提供 Flutter 依赖许可证页；发布包会额外生成覆盖 Go 与 Flutter 运行时依赖的许可证文件。更新检查留待 M4 后续。

## 数据与安全边界

- 主题、语言、工作区布局、通知、完成后动作、快捷键、关闭到托盘和“登录启动时静默运行”属于 Flutter 本机偏好，由 `PreferencesService` 持久化。
- “登录时启动”属于操作系统状态：macOS 13+ 由 `SMAppService` 管理，Windows/Linux 由系统登录项管理；界面每次以系统读回结果为准，不在 Flutter 偏好中复制该状态。手动启动始终显示窗口，托盘不可用时静默启动会安全回退为显示窗口。
- 下载、调度、网络、BT、数据与远程访问属于 Go 引擎业务设置，只能通过版本化 API 读写。
- 重名策略只提供 `fail` 与 `uniquify` 两个安全值：默认 `fail` 保持旧行为，`uniquify` 只为之后创建的 HTTP 任务生成副本名；两者都不能覆盖现有文件，BT 多文件任务仍保持冲突即停止。
- 完成后动作默认 `none`，可选 `revealFile`。它只响应客户端已知任务从非完成态实时进入 `completed` 的事件；启动、刷新或重连读取的历史完成任务不会触发。短时间内多项完成时通知仍逐项发送，但文件管理器只定位最后完成的一项。
- 代理密码、远程令牌等敏感值不进入 GetStorage、普通日志或诊断包；界面仅持有安全引用。
- 诊断 API 和 ZIP 只包含版本/运行时、缩写路径、安全设置摘要、数据库大小与任务计数，不包含任务 URL、Header、Cookie、代理凭据、Magnet、Torrent 元数据、文件名、单个任务保存路径或任务标识。当前版本没有落盘日志时必须明确报告不可用，不能为菜单虚构日志文件。
- 设置更新必须返回引擎已接受的最终值，Flutter 不乐观持久化业务配置。

## 通用验收标准

1. 宽屏只显示当前分组内容，窄屏继续使用菜单到详情的主从导航。
2. 每个控件必须说明生效时机、作用范围和对进行中任务的影响。
3. 支持中英文、200% 文字缩放、键盘焦点和读屏语义，长路径与长错误不溢出。
4. 业务设置写入失败时保留服务端原值并显示本地化错误，不伪装成已保存。
5. 新增菜单需要 Widget 测试；涉及引擎设置时同时覆盖 API 契约、校验、持久化和重启恢复。
